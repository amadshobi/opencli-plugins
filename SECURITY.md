## Reporting a Vulnerability

We take the security and privacy of our users very seriously. Since these plugins interact with authenticated browser sessions, safeguarding session cookies, local file paths, and user input is our top priority.

If you discover a security vulnerability or credential leak risk:

1. **Do not create a public issue.**
2. Send an email with vulnerability details to `amadshobi@users.noreply.github.com` or open a private security advisory on GitHub via the **Security** tab.
3. Please provide:
   - Description of the vulnerability.
   - Proof of Concept (PoC) or reproducible steps.
   - Potential impact.

We will acknowledge receipt within 48 hours and work with you on a timely fix before public disclosure.
